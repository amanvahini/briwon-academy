## 🌟 Executive Overview

## 🎨 Visual Identity & Design System

### 1. Logo & Brand Mark
- **Official Brand Mark**: Uses the high-resolution logo asset (`briwon-logo.png`).
- **Design Philosophy**: Solid, dark corporate navy text (`#163267`) complemented by a dynamic cyan-to-azure wave accent inside the circular "O".
- **Rule**: Never distorted, recolored, or replaced with generic placeholders.

### 2. Color Palette
| Token | Hex | Role | Usage |
|---|---|---|---|

## 🚀 How to Run & Preview

### Option 1: Instant Browser Preview (Zero Installation)
Simply double-click or open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
```bash
# Or serve with Python:
python -m http.server 3000
# Visit http://localhost:3000
```

### Option 2: Modern React / Vite Development Server
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
